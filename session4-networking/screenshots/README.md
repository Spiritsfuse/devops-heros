# Session 4 Screenshots

This directory stores verified execution screenshots for networking diagnostics:
- `01_ping.png`: Network reachability and ICMP round-trip latency via `ping`.
- `02_traceroute.png`: Path tracing and hop-by-hop latency via `traceroute`.
- `03_netstat.png`: Active network connections and listening ports via `netstat`.
- `04_telnet.png`: Port connectivity verification via `telnet`.
- `05_tcpdump.png`: Live packet capture and network inspection via `tcpdump`.
- `06_nslookup.png`: DNS name resolution query via `nslookup`.
- `07_dig.png`: Detailed DNS records query via `dig`.
- `08_curl.png`: HTTP request execution and response headers via `curl`.
- `09_arp.png`: Address Resolution Protocol table inspection via `arp`.
- `10_systemctl.png`: Network service state management via `systemctl status`.
